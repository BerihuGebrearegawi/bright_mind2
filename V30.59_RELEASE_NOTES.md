# Bright Mind Tutor V30.59

## Security and production hardening
- Moved the ImgBB API key out of browser JavaScript and into the server environment variable `IMGBB_API_KEY`.
- Added authenticated `/api/storage/image` upload proxy with image MIME validation and 15 MB server-side size enforcement.
- Client image uploads now use the authenticated BMT storage endpoint instead of sending the ImgBB key from the browser.
- Raised the global multipart request ceiling to 32 MB to support the existing 15 MB image policy and larger document/video workflows; individual upload endpoints continue to enforce their own limits.
- Updated health/readiness version markers to 30.59.
- Preserved Firebase, Gemini, Telebirr/CBE, authentication, payment, CORS, rate limiting, and security-header behavior.
