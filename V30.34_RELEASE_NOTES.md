# Bright Mind Tutor V30.34

## Baseline
V30.33

## Focus
Production reliability, observability, deployment readiness, and consistent API authentication errors.

## Changes
- Added response timing telemetry via `X-Response-Time-Ms`.
- Added `Strict-Transport-Security` only for HTTPS requests or when explicitly enabled with `FORCE_HSTS=1`.
- Added `/readyz` deployment readiness endpoint without exposing secrets.
- Updated `/healthz` to report V30.34.
- Added consistent `requestId` to user/admin authentication error responses.
- Hardened bearer-token parsing against empty bearer values.
- Preserved existing V30.33 CORS and Firebase custom-claim authorization model.
- Preserved payment, teacher approval, AI Tutor, parent, assessment, and analytics functionality.

## Validation
- Python compilation: passed.
- JavaScript syntax checks: passed where Node.js is available.
- Sensitive-secret source scan: passed for common key patterns.
- ZIP integrity: passed.

## Deployment Notes
Recommended production environment variables:
- `FIREBASE_SERVICE_ACCOUNT_JSON`
- `GEMINI_API_KEY`
- `ALLOWED_ORIGINS`
- `FORCE_HSTS=1` when TLS is guaranteed at the deployment boundary.

`/readyz` returns HTTP 503 when Firebase server credentials are missing. AI readiness is reported separately and does not block basic Firebase readiness.
