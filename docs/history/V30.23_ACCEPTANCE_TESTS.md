# V30.23 Acceptance Tests

- Teacher can see only authorized classes and students.
- Teacher cannot see another organization's analytics.
- Admin analytics are organization-scoped.
- Revenue includes only VERIFIED payments.
- Refunded payments reduce net revenue.
- Pending/failed payments are excluded from revenue.
- Client-supplied prices are never used for revenue aggregation.
- Analytics endpoints enforce role authorization server-side.
- Aggregated dashboards minimize exposure of student private data.
