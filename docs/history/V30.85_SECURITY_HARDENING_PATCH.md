# BMT V30.85 Security Hardening Patch

This patch hardens the existing V30.85 Community + AI release without changing the product version.

## Fixed in priority order

### P0. Paid video authorization
- Firestore video documents are no longer browser-readable.
- Students request video metadata through `/api/videos`.
- Paid video URLs are returned only when the authenticated user has an active server-side entitlement or an eligible free trial.
- Free video metadata remains available through the same authorized API.

### P0. Quiz answer-key exposure
- Firestore quiz documents are no longer browser-readable.
- Students request sanitized quiz questions through `/api/quizzes`.
- `correctAnswer` is never returned by the student quiz API.
- Quiz grading remains server-authoritative through `/api/quiz-results`.

### P1. User-document creation hardening
- User creation now uses an explicit field allowlist.
- Client-created profiles cannot set admin or paid status.
- Initial payment/free-trial invariants are enforced by Firestore rules.

### P1. Community role authorization
- Community reply role is resolved from Firebase admin claims and the approved `teachers/{uid}` record.
- The server no longer trusts `users.role` or client-supplied teacher flags for authorization.

### P1. Upload ceiling consistency
- Flask request ceiling increased from 32 MB to 100 MB to match the GCS document limit.

### P2. PWA cache consistency
- Service-worker cache updated from V30.74 to V30.85.

### Regression suite
- Legacy V30.73-V30.78 regression checks were updated to validate the current V30.85 baseline instead of obsolete version numbers and storage assumptions.
- New V30.85 security checks cover quiz answer-key isolation, video URL authorization, user-field allowlisting, and service-worker versioning.
