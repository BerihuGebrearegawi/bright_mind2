# BMT V31.00 — Critical Reliability + Parent + Recovery + Library

## Added
- Responsive animated landing logo.
- Parent dashboard navigation and verified parent-child analytics portal.
- Server-authoritative password reset request endpoint using Firebase Identity Toolkit.
- Shared Forgot Password UI for student, teacher, admin and parent portals.
- Community image/audio/video upload endpoint with Cloudinary validation.
- Admin community composer and teacher media/voice controls.
- Exam archive Free/Paid labels and visible price metadata.
- Digital Library Grade 3–12 category filters.
- Gemini AI translation endpoint and library translator UI.
- Cleaner 503 JSON responses for teacher profile/admin control center.

## Production environment
- `FIREBASE_WEB_API_KEY` required for backend password-reset requests.
- `PASSWORD_RESET_CONTINUE_URL` optional.
- `DIAGNOSTIC_KEY` optional but recommended for diagnostics.
- Existing Firebase service-account, Gemini and Cloudinary variables remain required by their respective features.


## V31.01 — Examination Data Model & Results Hardening
- Added server-side `passMark`, `maxAttempts`, and `totalPoints` to teacher-created exams.
- Enforced maximum attempts at `/api/exams/start`.
- Prevented teacher/admin exam attempts when role claim is present.
- Hardened `/api/exams/result/<attempt_id>` to require submitted status.
- Added server-generated PASS/FAIL and question-level result review.
- Added teacher controls for pass mark and maximum attempts.
- Updated student result UI to show PASS/FAIL and detailed answer review.
