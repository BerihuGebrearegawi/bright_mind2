# V30.63 Release Notes

## Password visibility control
- Added an eye-button to every password input in Student, Admin, and Parent authentication screens.
- Default state remains hidden.
- Users can explicitly show or hide the password while typing.
- Accessible labels and keyboard focus behavior are included.
- Existing password validation and Firebase authentication flows are unchanged.
- Dynamic password inputs are also detected by a MutationObserver.

## Scope
This release does not modify Firebase, Gemini, Telebirr, CBE, or deployment environment credentials.
