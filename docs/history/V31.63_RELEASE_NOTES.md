# BMT V31.63 — Qualification & Prize Allocation Integrity

## Changes
- Seasonal qualification now requires a valid submitted result for every required round through the configured 5/7-round target.
- Prize distribution uses integer cents with deterministic remainder allocation, guaranteeing the ledger total equals the computed prize pool.
- Existing Cloud B Digital Library / Scanner / Book Reader integration is untouched.
- Existing server-authoritative grading, award finalization, certificate verification, and publication protections are preserved.
