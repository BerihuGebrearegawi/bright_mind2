# V30.20 Acceptance Tests

- Unenrolled student cannot join a live class.
- Student from another grade/section cannot join.
- Student cannot create or edit attendance directly in Firestore.
- Join time is created by the server.
- Leave time and duration are calculated by the server.
- Repeated join requests do not create duplicate active attendance sessions.
- Recording is unavailable before publication.
- Unauthorized students cannot obtain recording URLs.
- AI summary is inaccessible until READY.
- AI summary is only visible to authorized students.
- Practice answers are graded server-side.
- Missing/failed transcript does not unlock a fabricated summary.
