# V31.58 — Seasonal Qualification Gate

Final award preview and final award ledger now apply the same server-side 5/7-round qualification gate when a challenge belongs to a named season. For each student, the best submitted result for each round is used; every round from 1 through the target round must meet the published advancement threshold. Non-seasonal challenges retain the existing single-challenge behavior. ChatGPT A / Cloud B library, scanner, and reader code is untouched.
