# BMT V31.65 — B-side ownership cleanup

This release keeps B responsible for Question Bank, Practice, Academic/Timed Challenge, server grading, qualification, leaderboard, awards, certificates, and Academic Challenge Telegram integration.

Removed from the B package because Cloud-B owns them:
- duplicate Digital Library structure routes and direct `libraryChapters` / `librarySubchapters` access
- duplicate Scanner routes and direct `libraryScanManifests` rules
- duplicate Question Bank location endpoint that directly validated Cloud-B hierarchy

The existing B-owned challenge/question collections remain server-authoritative. No new Library bookmark system is introduced; the existing BMT `bookmarks/{uid}` architecture remains the integration point.

Validation performed:
- Python compilation of B package source/tests
- ownership-boundary regression test
- residual search for removed Library/Scanner implementations

Live Firebase/Telegram production tests were not performed because production credentials/network access are not available in this environment.
