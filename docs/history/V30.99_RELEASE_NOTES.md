# Bright Mind Tutor V30.99

## 10X merge hardening

- Preserved the V30.98 teacher validation and existing Book/Video server-authoritative endpoints.
- Exposed all five student window handlers required by legacy HTML: register, logout, bookmarks, reply send, and reply cancel.
- Added server-authoritative admin quiz creation/listing at `/api/admin/catalog/quizzes`; removed direct client Firestore creation from the admin quiz form.
- Added optional `DIAGNOSTIC_KEY` / `X-Diagnostic-Key` access for non-secret `/api/admin/config-status` diagnostics when Firebase admin credentials are unavailable.
- Bumped health/readiness and service-worker cache versions to V30.99.
- Made Cloudinary the default book/PDF provider in the admin UI while retaining GCS and Google Drive as explicit alternatives.
- Added regression checks for the above changes.

## Security

- Quiz creation remains admin-authorized and validates class, options, answer choice, and Cloudinary image URLs server-side.
- Diagnostic output contains configuration booleans only, never credential values.
