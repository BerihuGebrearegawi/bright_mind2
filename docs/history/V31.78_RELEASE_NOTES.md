# BMT V31.78 — Unified Auth + Family & Parent Experience

## Included
- Unified Student/Teacher/Parent sign-in box: Email OR Phone Number + Password/PIN.
- Parent-child connection by secure BMT Parent Link Code.
- Student UI for generating/copying/regenerating the parent link code.
- Server-authoritative private messaging for verified Parent↔Student and Parent↔Teacher relationships.
- Parent dashboard: child linking, private contacts, family/teacher messaging.
- Parent Child Development & Parenting Center with practical learning modules and server-saved completion progress.
- Teacher UI for private parent communication.
- Preserved existing Community Chat, Firebase auth, Admin permissions, dashboards, library, scanner, and existing APIs.

## Security boundaries
- Parent-child access requires a verified `parentChildLinks` relationship.
- Private messaging checks the relationship server-side before reading or writing messages.
- Parent link codes are generated server-side and can be regenerated by the student.
- No API keys or credentials are embedded in client code.
