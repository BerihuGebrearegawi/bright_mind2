# BMT V31.19 — Auth UX + Phone/PIN

## Included
- Modernized landing page with a single, clean navigation path.
- Student authentication redesigned to remove duplicated Sign In controls.
- Student email/password login retained.
- Student phone + PIN registration/login added.
- Teacher phone + PIN registration/login added.
- Parent phone + PIN registration/login added.
- Optional SMS verification step added for phone login flows.
- PINs are hashed server-side with scrypt and stored outside the client-readable `users` document in `authSecrets`.
- Phone/PIN login uses Firebase Admin custom tokens after server-side PIN verification.
- Existing email/password authentication is preserved.
- Admin Student/Teacher/Parent preview flow remains server-authorized and does not require the previewed role to authenticate.
- Service-worker cache bumped to v31-19.

## Validation
- Python compile: PASS
- JavaScript syntax: PASS
- HTML parse: PASS

## Important deployment requirements
- `FIREBASE_SERVICE_ACCOUNT_JSON` (or the existing supported Firebase credential variables) must be configured on Render for Phone/PIN server endpoints.
- `ADMIN_PREVIEW_SECRET` or `SECRET_KEY` must be configured for Admin Preview tokens.
- For optional SMS verification, Firebase Phone Authentication must be enabled and the Render production domain must be an authorized Firebase Auth domain.
