# BMT V31.55 — Leaderboard/Submission Consistency Hardening

Additive hardening of the BMT Academic Challenge backend.

Changes:
- Persist server-derived `statusResult` on finalized attempts so idempotent resubmission returns the original result.
- Align leaderboard duplicate-attempt selection with award-ledger ordering: percentage, score, earliest submission, stable user ID.
- Paid-challenge leaderboard rows require a verified challenge entry.
- Preserve server-authoritative grading and immutable question snapshots.
- No ChatGPT A-owned UI/auth/payment implementation is modified by this release.
