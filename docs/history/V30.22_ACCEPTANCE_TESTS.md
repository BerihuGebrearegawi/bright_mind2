# V30.22 Acceptance Tests

- User can read only their own notifications.
- User cannot create arbitrary notifications.
- User cannot modify notification title/body/type.
- User can mark their own notification as read.
- User cannot mark another user's notification as read.
- Read-all affects only the authenticated recipient.
- A scheduled reminder is sent at most once per idempotency key.
- Live class reminders respect Africa/Addis_Ababa scheduling.
- Expired notifications are not shown as active.
- Failed email delivery is logged and retryable.
