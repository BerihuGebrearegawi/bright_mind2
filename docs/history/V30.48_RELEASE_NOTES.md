# Bright Mind Tutor V30.48

## Focus
Production reliability for Gemini-backed AI Tutor and practice-quiz generation.

## Changes
- Added bounded exponential backoff for transient Gemini network/429/5xx failures in practice-quiz generation.
- Reused `GEMINI_TIMEOUT_SECONDS` and `GEMINI_MAX_ATTEMPTS` for quiz generation, matching the Tutor gateway controls.
- Added safe handling for invalid Gemini JSON responses.
- Updated `/healthz` and `/readyz` version to 30.48.
- Preserved Firebase, admin claims, payment HMAC, amount/currency validation, idempotency, CORS, rate limiting and security headers.
