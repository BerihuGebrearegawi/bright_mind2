# Bright Mind Tutor V30.86 — Production Candidate

## Purpose
V30.86 continues the V30.85 security-hardening baseline and closes the next production-access-control gaps without changing the Community + AI product scope.

## P1/P2 fixes

### GCS signed-document authorization
- `/api/storage/document-url` no longer signs an arbitrary `bmt/*` path for any authenticated user.
- A signed URL is minted only for a known Firestore `books` record whose GCS path exactly matches the requested path.
- Students must match the book's class.
- Teachers may access content explicitly assigned/uploaded to their UID.
- Admins retain access.
- Non-book GCS paths are rejected by this endpoint.

### Firebase Storage hardening
- Profile images require authentication to read.
- Legacy book, video, and quiz-image storage paths require authentication to read.
- Admin-only write/delete permissions remain unchanged.
- The application continues to use Cloudinary/GCS for current media/document flows.

### Release consistency
- Runtime health/readiness version is V30.86.
- PWA cache is V30.86.
- Regression scripts now target the V30.86 baseline.
