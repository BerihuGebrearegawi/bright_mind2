# Bright Mind Tutor V30.36 Release Notes

## Focus
Reliability, API abuse resistance, proxy correctness, and production diagnostics.

## Changes
- Rate limiting now avoids trusting spoofable `X-Forwarded-For` by default.
- `TRUST_PROXY_HEADERS=1` explicitly enables proxy-header trust for deployments that require it.
- Rate-limit memory is periodically pruned to prevent unbounded process-local growth.
- HTTP 429 responses include `Retry-After`.
- Added a consistent JSON 400 error response with request ID.
- Updated health version to 30.36.
- Preserved V30.35 authentication, Firebase revocation checks, CORS restrictions, HSTS, payment security, AI security, and admin/teacher authorization.
