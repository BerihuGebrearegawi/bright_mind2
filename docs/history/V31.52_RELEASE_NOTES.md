# BMT V31.52 — Challenge Integrity & Finalization Hardening

## Scope
This release is additive to the V31.51 verification-hardened baseline. It does not redesign or replace ChatGPT A-owned UI/auth/payment implementation.

## Repairs
- Challenge submission is rejected once the published challenge end time has passed, closing the late-submit/finalization race.
- Award finalization refuses to proceed while any challenge attempt remains open.
- Paid challenge awards are restricted to users with verified entries for the same challenge.
- Award finalization is idempotent when the challenge already has an awards-finalized marker.
- Prize remainder is assigned deterministically so the published ledger accounts for the full rounded pool.
- Existing server-authoritative question snapshots and payment verification gates remain intact.
