# V31.108 — KaTeX Math Rendering Across All Dashboards

## Problem
Student, Teacher, Parent, and Admin dashboards had no math/formula rendering.
AI Tutor, Homework Coach, Homework Image, Study Plan, quiz, and exam question
text containing LaTeX (e.g. `$x^2 + 1$`) displayed as raw, unreadable text.

## Fix
- Added KaTeX 0.16.11 (CSS + core + auto-render extension) via jsdelivr CDN,
  with Subresource Integrity (SRI) hashes, to the `<head>` of `student.html`,
  `teacher.html`, `parent.html`, and `admin.html`.
- All three script tags use `defer` (not a mix of `defer`/`async`), so they
  execute once, in source order, after the HTML is parsed — the same pattern
  already used elsewhere in BMT to avoid CDN script race conditions.
- Added `static/math-render.js`: a small shared script that renders
  `$...$` / `$$...$$` / `\(...\)` / `\[...\]` delimiters wherever they appear,
  using a `MutationObserver` on `document.body`. This means every existing
  and future `innerHTML` call site (AI Tutor chat, Homework Coach/Image,
  Study Plan, quiz cards, exam runner, community/private chat, assignment
  feedback, etc. across `student.js`, `teacher.js`, `admin.js`) gets math
  rendering automatically, without editing each call site individually.
- `window.BMTRenderMath(el)` is exposed for any script that wants to force
  an immediate render right after writing content, instead of waiting for
  the observer's next animation frame.

## Scope
Additive only. No existing route, script, or template behavior was changed;
only new `<head>` assets and one new static file were added.
