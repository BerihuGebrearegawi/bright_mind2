# Bright Mind Tutor V30.23 — Teacher Analytics + Admin Analytics + Revenue Dashboard

## Teacher Analytics

Teachers can see only authorized classes/courses.

Metrics:
- Student count
- Active students
- Attendance rate
- Assignment completion
- Assessment average
- Topic mastery
- At-risk students
- Course completion
- Live-class participation

## Admin Analytics

Admin dashboard aggregates organization-level metrics:

Users:
- Students
- Teachers
- Parents
- Active users

Learning:
- Courses
- Enrollments
- Completion rate
- Assessment performance
- Attendance
- AI tutor usage

Operations:
- Live classes
- Notifications
- Failed jobs
- Storage usage

## Revenue Dashboard

Metrics:
- Gross revenue
- Successful payments
- Pending payments
- Failed payments
- Refunds
- Net revenue
- Revenue by course
- Revenue by period
- Revenue by payment provider

Revenue must be calculated from verified payment records only.

Formula:

netRevenue = verifiedRevenue - refundedAmount

Never calculate revenue from client-submitted amounts.

## API

Teacher:
GET /api/teacher/analytics/overview
GET /api/teacher/analytics/students
GET /api/teacher/analytics/topics

Admin:
GET /api/admin/analytics/overview
GET /api/admin/analytics/revenue
GET /api/admin/analytics/engagement

All analytics endpoints require server-side role and organization authorization.

## Privacy

Teacher analytics must not expose unrelated organizations.
Admin analytics are organization-scoped unless the account has explicit platform-level permissions.
Parent/student private data should be aggregated or minimized in analytics responses.
