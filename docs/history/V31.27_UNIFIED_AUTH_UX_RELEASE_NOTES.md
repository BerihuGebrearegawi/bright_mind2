# BMT V31.27 — Unified Authentication UX

## Changes
- Modernized Sign In / Register access on Student and Teacher portals.
- Kept Email + Password and Phone + PIN as clear choices inside the same auth card.
- Kept optional SMS OTP available for phone login without making OTP mandatory.
- Added a compact, accessible auth-mode switch for Teacher login/registration.
- Improved auth controls with consistent active states, spacing, focus-friendly sizing and transition.
- Fixed a critical Student Phone + PIN registration bug: the JS was reading `phoneRegClass`, while the form uses `regClass`. Phone registration now submits the selected class correctly.
- Preserved existing Firebase Auth, Flask API contracts, role checks and dashboard functionality.
- Updated service-worker cache version to 31.27.
