# BMT V31.36 — Parallel Library Structure + Challenge Contract

## Implemented
- Added an isolated server-authoritative subchapter creation endpoint for approved teachers/admins.
- Added book-scoped chapter structure retrieval with ordered subchapters.
- Added explicit `librarySubchapters` Firestore browser-deny rule.
- Preserved existing Digital Library UX/clarity contracts; no A-owned frontend UX was rewritten.
- Preserved server-authoritative challenge scoring, timer/deadline, approval, round, and qualification controls.

## Security
- Subchapter creation requires authenticated approved teacher/admin access.
- A subchapter must reference an existing chapter; its bookId is inherited server-side from the chapter.
- Chapter retrieval rejects a chapter that belongs to a different book.
- New subchapter records are server-only in Firestore.
- No client-supplied score, rank, qualification, or answer key is trusted.
