# Bright Mind Tutor V30.22 — Notification Center + Reminder Engine

## Notification Center

### Notification types
- ASSIGNMENT
- LIVE_CLASS
- EXAM
- ATTENDANCE
- PAYMENT
- COURSE
- AI_SUMMARY
- SYSTEM

### Notification lifecycle
UNREAD -> READ
Optional:
UNREAD -> DISMISSED

Notifications must be created by trusted server-side events.

## Reminder engine

Supported reminders:
1. Live class reminder
2. Assignment due reminder
3. Exam reminder
4. Payment/enrollment reminder
5. New lesson/course announcement

Recommended reminder schedule:
- Live class: 24 hours and 30 minutes before
- Assignment: 24 hours before due time
- Exam: 24 hours and 1 hour before

Schedules should be configurable per organization.

## Channels

MVP:
- In-app
- Email

Future:
- Push
- SMS
- Telegram

## Security
- Recipient UID is server-controlled.
- A user may read only their own notifications.
- Read state may be changed only by the recipient.
- Notification content cannot be rewritten by the recipient.
- Email addresses are obtained from the authenticated profile/server records.
- Duplicate reminders use an idempotency key.

## API

GET /api/notifications
POST /api/notifications/<id>/read
POST /api/notifications/read-all
GET /api/notifications/preferences
PATCH /api/notifications/preferences

The server creates notifications. Clients cannot create arbitrary notifications.

## Event flow

Domain Event
  -> Notification Service
  -> Idempotency Check
  -> Schedule
  -> Channel Adapter
