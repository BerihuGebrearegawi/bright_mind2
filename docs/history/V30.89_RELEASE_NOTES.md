# Bright Mind Tutor V30.89

## Production stabilization
- Firebase Admin credentials now support a single JSON secret, base64 JSON, credential file, or separate Render environment variables.
- Google Cloud Storage uses the same credential fallback logic as Firebase Admin.
- Admin configuration diagnostics now include Cloudinary readiness without exposing secrets.
- Teacher application now collects education level, institution, experience years, experience details, and certifications.
- Admin teacher-request view displays the submitted professional profile before approval.

## Safety
- No Firebase rules were loosened.
- No client-side service-account credentials were added.
- Existing approved-teacher/admin authorization remains server authoritative.

## V30.89 patch — registration and admin media hardening
- Fixed Student Login/Register forms: ES-module functions are now explicitly exposed to the inline form handlers.
- Added a server-authoritative `/api/admin/storage/cloudinary` endpoint protected by Firebase admin claims.
- Admin video and quiz-image uploads now use the protected server endpoint instead of calling Cloudinary directly from the browser.
- Kept student profile/media uploads on the existing general storage path so normal student functionality is preserved.
- Added MIME/type and size validation to the admin Cloudinary endpoint.
- Added signed Cloudinary upload support when `CLOUDINARY_API_KEY` and `CLOUDINARY_API_SECRET` are configured, with a protected unsigned-preset fallback for existing deployments.
- No Firestore security rules were loosened.
