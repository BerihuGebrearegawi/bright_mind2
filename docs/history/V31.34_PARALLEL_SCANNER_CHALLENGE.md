# BMT V31.34 — Parallel Scanner + Challenge Hardening

## Scope
- Added an isolated server-authoritative scanner intake manifest.
- Scan pages are normalized and sorted by page number once at registration.
- Duplicate page numbers, invalid page numbers, and oversized batches are rejected.
- Scanner manifest Firestore records are server-only.
- No OCR or AI generation was added in this release; this keeps the scanner path cost-conscious and separate from existing AI material ingestion.
- Hardened challenge answer autosave with a Firestore transaction to prevent stale concurrent writes from replacing a newer attempt state.

## Ownership boundary
- This release only touches the parallel scanner/challenge foundation.
- Existing Digital Library UX/clarity work is not duplicated or rewritten.
