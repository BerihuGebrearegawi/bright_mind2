# Bright Mind Tutor V15 — Student Learning Dashboard

## New
- Live classes now support Grades 3–12.
- Teacher application/live-class selectors support Grades 3–12.
- `/api/student/progress` aggregates existing progress, exam attempts, courses, AI daily usage, and upcoming live classes.
- Student dashboard shows videos watched, quiz average, exam average, courses completed, AI usage, and upcoming live classes.

## Storage
No PDF/video binaries are moved into Firestore. Existing Google Drive, Cloudinary, ImgBB, and Firestore architecture remains intact.
