# V31.64 — Telegram Academic Challenge Integration

## Scope
Additive Telegram bot/webhook integration for the BMT Academic Challenge. It does not modify the Cloud-B Digital Library, Scanner, or Book Reader.

## Environment
- `TELEGRAM_BOT_TOKEN` — server secret; never commit it.
- `TELEGRAM_WEBHOOK_SECRET` — secret token sent in `X-Telegram-Bot-Api-Secret-Token`.
- Optional `TELEGRAM_MAX_MESSAGE_LENGTH` — default 3500.

## Identity
A Telegram account must be linked to an approved student through `users.telegramUserId`. The bot never trusts a client-supplied UID.

## Commands
`/start`, `/help`, `/challenges`, `/startchallenge CHALLENGE_ID`, `/answer QUESTION_ID OPTION`, `/submit`, `/result`.

## Security boundary
- Webhook secret is required and compared with constant-time comparison.
- Answer keys remain server-side.
- Challenge start snapshots approved questions.
- Paid challenges require a verified `challengeEntries` record.
- Attempt identity is deterministic per student/challenge.
- Score and percentage are computed server-side.
- Telegram is only a transport/interface layer.

## Deployment
Configure the secrets in the deployment environment, then set the Telegram webhook to:
`POST /api/telegram/webhook`
using Telegram's secret-token header. Do not place the bot token or webhook secret in source control.

## Integration note
This module is intended to be reviewed by ChatGPT A against the Cloud-B library contract before production activation.
