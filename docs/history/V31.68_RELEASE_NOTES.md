# BMT V31.68 — B-side Lifecycle Regression Hardening

Scope: ChatGPT B ownership only.

## Fixes
- Publish endpoint now permits only DRAFT → PUBLISHED transitions.
- Submission endpoint now enforces challenge lifecycle state server-side.
- Manually CLOSED challenges cannot accept submissions while an attempt still has time remaining.
- Schedule-expired CLOSED challenges can finalize already-started attempts using only durably saved answers.
- ACTIVE challenges that pass their configured end time are treated as expired for submission grading.
- Prevented lifecycle dead-ends that could leave open attempts blocking award finalization.

## Ownership
- No Cloud-B Library/Scanner/Reader routes added.
- No new bookmark system added.
- No core Auth/RBAC or payment engine added.
- B-side Question Bank, Academic Challenge, grading, qualification, leaderboard, awards, certificates, and Telegram Challenge remain in scope.
