# BMT V30.80

## Assignment workflow
- Students can submit written answers and optional document/project links.
- Students can view submission status and graded feedback.
- Teachers can open submissions for assignments they own.
- Teachers can grade with score/max score and feedback.
- Server validates teacher ownership, student grade, assignment status, deadline, and submission ownership.
- Graded submissions become read-only to students.

## Security
- Assignment writes and grading are server-authoritative.
- No client-supplied teacher UID is trusted.
- Student submissions are restricted to the authenticated student.
