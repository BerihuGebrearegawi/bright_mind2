# Bright Mind Tutor V30.94

## Careful Quality Patch

### Fixed
- Organization logo upload no longer relies on hard-coded Cloudinary cloud/preset values.
- Logo upload now uses the same server-side Cloudinary configuration strategy as protected admin media uploads.
- Signed Cloudinary upload is preferred when `CLOUDINARY_API_KEY` and `CLOUDINARY_API_SECRET` are configured.
- Unsigned preset fallback remains available when `CLOUDINARY_UPLOAD_PRESET` is configured.
- Cloudinary failure responses now return a safe actionable message while never exposing credentials.

### Verification
- Python compilation passed for modified backend modules.
- No Firebase service-account secret was added to source code.
- Existing admin authorization path remains required for logo upload.

## Deployment note
Set the required Render environment variables before deployment:
- `CLOUDINARY_CLOUD_NAME`
- Prefer signed uploads: `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`
- Or configure `CLOUDINARY_UPLOAD_PRESET` as the fallback

Do not place the API secret in frontend JavaScript.
