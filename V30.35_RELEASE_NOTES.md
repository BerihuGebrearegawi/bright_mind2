# Bright Mind Tutor V30.35 Release Notes

## Focus
Authentication reliability, API abuse protection, deployment readiness, and security-header hardening.

## Changes
- Added bounded process-local API rate limiting with configurable window and request count.
- Hardened request-ID validation to prevent untrusted header values from being echoed.
- Added Cross-Origin-Opener-Policy and Cross-Origin-Resource-Policy headers.
- Firebase ID-token verification now requests revoked-token checking for user/admin authentication.
- Firebase service-account configuration is validated before the app reports readiness.
- `/readyz` now reflects actual Firebase initialization rather than environment-variable presence alone.
- `/healthz` version updated to 30.35.

## Compatibility
No payment, course, assessment, AI, parent, teacher, or admin feature was intentionally removed.

## Known limitation
The in-process rate limiter is suitable as a safety net for a single process. Multi-instance production deployments should also enforce equivalent limits at the edge/gateway.
