# Bright Mind Tutor V30.69

## Final hardening and Render production fixes

### Authentication and Firebase
- Added `uid` to student registration documents, matching Firestore create rules.
- Hardened `FIREBASE_SERVICE_ACCOUNT_JSON` loading for Render formatting differences.
- Added optional `FIREBASE_SERVICE_ACCOUNT_JSON_B64` and `FIREBASE_SERVICE_ACCOUNT_FILE` fallbacks.
- Admin server APIs now use Firebase Admin SDK for sensitive settings/moderation operations.

### Admin Control Center
- Organization logo upload now uses the authenticated server-side ImgBB proxy and server Firestore write.
- Service prices now use a secure admin API and support ETB/USD selection.
- Teacher requests now load through a server-authoritative admin endpoint.
- Push notification token collection now happens server-side instead of direct browser reads.
- Live stream settings now use server APIs and reject Telegram bot links as fake live streams.
- Admin chat moderation now supports reply, reactions, delete, and quote/reply context.

### Student experience
- Registration now complies with Firestore rules by writing the authenticated UID.
- Chat reactions added: heart, like, dislike and fire.
- Admin replies are shown as quoted/admin messages.
- Subscription pricing is loaded dynamically from the platform settings API and displays ETB/USD.

### Storage
- ImgBB image uploads now include the signed-in Firebase bearer token.
- This fixes logo/quiz image failures caused by the authenticated image proxy rejecting browser requests without a token.
- Cloudinary video uploads now have a five-minute client timeout and clearer provider error messages.
- Google Drive upload guidance now explains the OAuth Authorized JavaScript Origins requirement for Render.

### Exam archive
- Grade 6 through Grade 12 are supported.
- Grade 12 requires Natural Sciences or Social Sciences.
- Google Drive preview and download URLs are generated automatically when only a file ID is supplied.
- Admin UI explains where to obtain the Google Drive file ID.

### Landing page
- Added a Teacher Dashboard entry point.
- Existing CBE/TeleBirr payment account information remains absent from `index.html`.
