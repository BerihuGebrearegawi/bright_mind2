# BMT V30.83 Storage Hardening

## Production routing
- Render: Flask application/API
- Firestore: database and metadata
- Cloudinary: images, videos, audio
- Google Cloud Storage: books and PDF/DOC/DOCX documents

## Hardening completed
- Removed ImgBB from the primary browser storage service.
- Removed stale Google Drive OAuth upload code from the primary storage service.
- Implemented the missing Cloudinary upload function used by image/video/audio uploads.
- Kept Google Drive/Mega/External as legacy archive providers only.
- Kept GCS document uploads authenticated through Firebase bearer tokens.
- Kept short-lived GCS signed URLs for document access.
- Kept file-size and MIME validation.
- Preserved existing Firebase, payment, Gemini and chat security checks.

## Production environment
Required for GCS:
- `GCS_BUCKET_NAME`
- existing server-side Firebase service-account configuration

Cloudinary public upload configuration:
- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_UPLOAD_PRESET`

No credentials are bundled in the release ZIP.
