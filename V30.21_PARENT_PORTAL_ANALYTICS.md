# Bright Mind Tutor V30.21 — Parent Portal + Student Progress Analytics

## Parent Portal
Parent access must be based on a verified parent-child relationship.

### Parent dashboard
- Children list
- Current grade and class group
- Course progress
- Assessment performance
- Attendance
- Assignment completion
- Weak topics
- Recent learning activity
- Payment/enrollment status

### Security
A parent may read only data belonging to verified linked children.
Students cannot read parent-only analytics.
A parent cannot change assessment scores, attendance, enrollment, or teacher records.

## Student Progress Analytics

### Core metrics
- Course completion percentage
- Lesson completion
- Assessment average
- Topic mastery
- Attendance rate
- Assignment completion
- Learning activity
- AI tutor usage

### Mastery calculation
Use server-side aggregation from trusted learning events.

Recommended mastery bands:
- 0–39: Needs Support
- 40–59: Developing
- 60–79: Proficient
- 80–100: Mastered

These thresholds should remain configurable.

## Risk indicator
Use multiple signals rather than one score:
- sustained low assessment performance
- missing assignments
- declining attendance
- declining learning activity

Risk levels:
LOW / MEDIUM / HIGH

Risk is an intervention signal, not a final judgment.
