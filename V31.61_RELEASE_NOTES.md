# BMT V31.61 — Student Award Center & Certificate Verification Hardening

## Scope
Additive hardening of the BMT Academic Challenge award/certificate layer. Cloud B Digital Library/Scanner/Book Reader code is not modified.

## Changes
- Certificate public verification now validates the stored HMAC signature when `BMT_CERT_VERIFY_SECRET` is configured.
- Student award history changed from a broad document-field copy to an explicit allow-list, preventing accidental exposure of admin UIDs, payment metadata, and internal audit fields.
- Student award history ordering now uses the authoritative `awardsFinalizedAt` field.
- Existing server-authoritative certificate issuance, award finalization, winner publication, and Firestore browser-deny rules remain intact.
