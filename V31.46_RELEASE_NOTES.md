# BMT V31.46 — Secure Challenge Start Gate

## Scope
Additive hardening for the BMT Academic Challenge track only. No ChatGPT A-owned UI/payment implementation was intentionally modified.

## Changes
- Paid challenges now require a server-verified `challengeEntries` record before `/api/challenges/start`.
- Free challenges remain startable without a payment entry.
- Challenge attempt IDs are deterministic per authenticated student + challenge, preventing start-replay from creating multiple attempts.
- A previously submitted attempt cannot be restarted.
- Existing server-authoritative scoring, timer, question approval, and Firestore-deny rules remain in place.

## Security intent
The browser cannot turn an unverified payment into a challenge start, and repeated start requests cannot mint parallel attempts for the same student/challenge.
