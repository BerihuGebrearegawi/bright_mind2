# BMT V31.11 — Exam E2E Hardened (Reissued)

## Exam lifecycle hardening
- Student exam start now requires a real `student` account and enforces the published exam class/grade when configured.
- Optional `startAt` / `endAt` publication windows are enforced server-side.
- Exam grading is now a Firestore transaction, preventing duplicate/concurrent grading of the same attempt.
- The browser can never supply or alter the answer key, points, topics, pass mark, score, or percentage.
- Late submissions use the last server-autosaved answers rather than trusting a late browser payload.
- Unknown answer IDs are ignored during grading.
- Parent exam-result notifications are created for verified parent-child links after a successful submission.
- Added `/api/parent/children/<child_id>/exams` for server-authoritative parent exam results.
- Added `/api/teacher/exams/<exam_id>/publish` for explicit teacher publishing of draft exams.
- Existing teacher result analytics remains server-authoritative.
