# Bright Mind Tutor V30.44 Release Notes

## Focus
Payment webhook verification hardening and regression-safe release validation.

## Changes
- Updated `/healthz` and `/readyz` to report V30.44.
- Hardened Telebirr/CBE generic webhook verification: verified-status callbacks now require a gateway amount by default.
- Preserved the existing constant-time HMAC signature check.
- Added optional `PAYMENT_CURRENCY` validation when the gateway supplies a currency field.
- Added explicit compatibility escape hatch `ALLOW_WEBHOOK_WITHOUT_AMOUNT=1` for gateways that cannot provide an amount; this is not recommended for production.
- Updated the safe smoke test to expect V30.44.
- Existing Firebase authentication, admin custom claims, AI gateway, rate limiting, CORS, request-ID, and other payment controls remain unchanged.

## Production guidance
Configure `TELEBIRR_WEBHOOK_SECRET`, `CBE_WEBHOOK_SECRET`, and preferably `PAYMENT_CURRENCY` as server environment variables. Do not put secrets in source or ZIP releases. Keep `ALLOW_WEBHOOK_WITHOUT_AMOUNT` unset in production unless the gateway contract genuinely cannot provide an amount and the risk has been reviewed.
