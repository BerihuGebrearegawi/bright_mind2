# V30.61 Release Notes

## Focus
Production reliability and API rate-limit response quality.

## Changes
- Bumped application/runtime release version to V30.61.
- Added `Retry-After` response header to API `429 Too Many Requests` responses.
- Preserved API-only, process-local rate limiting and existing security behavior.
- Updated release consistency and static regression expectations.
- Added a static rate-limit regression test.

## Validation
- Python syntax/compilation checks.
- Release consistency checks.
- Static production regression checks.
- Rate-limit regression checks.
- Secret/artifact scan.
- ZIP integrity check.

Live Firebase, Gemini, and Telebirr calls require the user's configured production/staging environment and are not claimed here.
