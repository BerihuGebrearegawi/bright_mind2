# BMT V31.07

## Changes
- Added authenticated, short-lived admin preview tokens for Student/Teacher/Parent dashboards.
- Removed the previous public query-string-only preview trust boundary.
- Added Admin Dashboard Preview controls.
- Added preview-link expiry and server-side HMAC validation.
- Hardened landing-page logo sizing so the logo scales with the pulsing container.
- Preserved existing authentication and dashboard flows.

## Required environment variable
Set `ADMIN_PREVIEW_SECRET` on Render and local development to a long random secret.
