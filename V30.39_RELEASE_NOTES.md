# Bright Mind Tutor V30.39 Release Notes

## Baseline
V30.38

## Focus
Deployment readiness reliability, health endpoint consistency, and safer operational diagnostics.

## Changes
- Updated `/healthz` to report V30.39.
- Hardened `/readyz` so unexpected Firebase initialization errors are handled without leaking provider details.
- `/readyz` now reports a non-secret `ai_configured` flag rather than implying that the AI provider is reachable.
- `/readyz` now includes the release version for deployment diagnostics.
- Preserved V30.38 response security headers, no-store behavior, rate limiting, request IDs, CORS restrictions, HSTS, and proxy-header controls.
- Preserved V30.37 custom-claim admin authorization and all payment/AI security controls.

## Validation
- Python syntax check: required and passed before packaging.
- JavaScript syntax check: required where Node.js is available.
- Secret/private-key scan: required before release.
- ZIP integrity: required before release.

## Known limitation
Live Firebase, Telebirr, Gemini, and production deployment checks require the deployment environment and credentials. Secrets must remain in environment variables and must not be included in the ZIP.
