# Bright Mind Tutor V30.38 Release Notes

## Baseline
V30.37

## Focus
Production hardening, response security headers, health-check cache safety, and release consistency.

## Changes
- Updated `/healthz` version to V30.38.
- Added `X-DNS-Prefetch-Control: off`.
- Added `X-Permitted-Cross-Domain-Policies: none`.
- Extended `Cache-Control: no-store` to `/healthz` and `/readyz` so deployment status is never cached.
- Preserved V30.37 Firebase custom-claim admin authorization.
- Preserved request IDs, rate limiting, proxy-header controls, CORS restrictions, HSTS, authentication revocation checks, payment security, and AI gateway protections.

## Validation
- Python syntax check required before release.
- JavaScript syntax check required before release where Node.js is available.
- Secret/private-key scan required before release.
- ZIP integrity check required before release.

## Known limitation
Live Firebase, Telebirr, Gemini, and production deployment checks require the deployment environment and credentials. Secrets must remain in environment variables and must not be included in the ZIP.
