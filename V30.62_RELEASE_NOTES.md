# V30.62 Release Notes

## Focus
Final offline production-readiness hardening. User-managed environment and live provider deployment remain external.

## Changes
- Bumped application/runtime release version to V30.62.
- Fixed stale V30.60 default in the public E2E smoke test.
- Included the public E2E smoke test in release-version consistency checks.
- Tightened Firestore chat access to the authenticated student's own class.
- Tightened typing-indicator writes to the caller's own UID field.
- Restricted direct browser creation of notifications to the server/Admin SDK.
- Restricted direct browser creation of exam attempts to the server/Admin SDK.
- Restricted direct browser access to only published exams for non-admin users.
- Replaced broad Firebase Storage authenticated-write fallback with least-privilege path rules.
- Added Render proxy-header configuration for correct client-IP rate limiting.
- Fixed Gemini Interactions REST response parsing to support the current `steps[].model_output` response shape.
- Set Gemini interactions to `store=false` because BMT manages student chat history itself and should not persist provider-side conversation data by default.

## Intentionally left for deployment owner

- Telebirr/CBE production credentials, native webhook signature mapping, and live payment callbacks.
- PAYMENT_CURRENCY and any business-specific pricing values.
- ALLOWED_ORIGINS/custom domain values.
