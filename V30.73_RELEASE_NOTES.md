# BMT V30.73 — Books: Google Drive Link Storage Option

- Added a second book/document source: Google Drive file link.
- Admin can choose Cloudinary upload or Google Drive link.
- Google Drive links are normalized to preview and download URLs.
- Supports files stored in a second Google Drive account when sharing is set to Anyone with the link → Viewer.
- Existing Cloudinary book uploads remain supported.
- Student book cards now show Preview and Download for Google Drive items.
- No Google OAuth is required for the link-based option.
