# Bright Mind Tutor V30.43 Release Notes

## Focus
Payment verification precision and production safety.

## Changes
- Gateway payment amount comparison now uses `Decimal` instead of binary floating-point arithmetic.
- Invalid stored payment amounts are rejected safely instead of being processed.
- When `PAYMENT_CURRENCY` is configured, a gateway webhook must provide a currency and it must match exactly.
- Existing V30.44 webhook signature, amount verification, idempotent payment IDs, and atomic entitlement updates are preserved.
- No secrets or credentials are included in the release.

## Validation
- Python compile check
- JavaScript syntax check
- Payment verification static checks
- Secret scan
- ZIP integrity check

## Production note
Use staging credentials first for live Firebase/Telebirr/CBE/Gemini smoke tests. Never place secrets in the ZIP or source repository.
