# V31.48 — Atomic Challenge Submission

Security-first continuation of the V31.47 challenge pipeline.

## Changes
- Challenge submission now finalizes the attempt inside a Firestore transaction.
- Concurrent submissions of the same attempt cannot both transition it from `started` to `submitted`.
- Server-only answer keys remain the sole grading authority.
- Expired attempts use only durably autosaved answers.
- Submitted answers are filtered against the immutable question set captured at challenge start.
- Score, percentage, pass/fail status, and counts remain server-derived.
- Client-supplied score/rank/prize fields are ignored.
- Grading version is recorded as `V31.48`.

## Boundary
- No ChatGPT A-owned UI/payment/auth modules were modified.
- No new AI provider or paid API dependency was introduced.
