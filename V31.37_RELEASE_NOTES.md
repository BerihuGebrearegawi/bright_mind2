# BMT V31.37 — Parallel Scanner → Question Bank

## Implemented
- Added a server-authoritative scanner-to-question-draft ingestion endpoint.
- Question drafts inherit `bookId` from the scan manifest, preventing client cross-book source spoofing.
- Drafts retain `sourceScanId` and a deterministic source reference for traceability.
- Ingestion is batched atomically with the scan status update.
- OCR/AI generation remains out of this endpoint to avoid unnecessary AI cost and preserve the existing content-review boundary.

## Security
- Requires authenticated approved teacher/admin access.
- Non-admins can ingest only their own scan manifests.
- All imported questions remain `draft` until separately approved.
- Existing Firestore browser-deny rules remain unchanged.

- Python compile check: pending runtime dependency validation.
- Existing A-owned frontend files were not modified.
