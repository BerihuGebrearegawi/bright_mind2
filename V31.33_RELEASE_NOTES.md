# BMT V31.33 — Parallel Library/Challenge Hardening

## Changes
- Hardened challenge leaderboard access: teacher visibility now requires an approved teacher record.
- Added optional server-validated `startsAt` / `endsAt` scheduling to challenge creation.
- Rejects malformed schedule timestamps and invalid end-before-start windows.
- Preserves existing Digital Library, authentication, payment, legacy quiz, and ChatGPT A-owned UX contracts.

## Security posture
- Challenge scoring remains server-authoritative.
- Correct answers remain excluded from student-facing question payloads.
- Challenge publication still re-validates that every question is approved.
- New schedule fields are additive and do not change existing challenge records.
