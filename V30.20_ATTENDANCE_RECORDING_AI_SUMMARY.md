# Bright Mind Tutor V30.20 — Attendance + Recording + AI Summary

## Attendance
Attendance is server-authoritative.

POST /api/live-classes/<class_id>/join
- Authenticate student.
- Verify enrollment and grade/class-group authorization.
- Verify the class is joinable.
- Create/update the student's attendance session.
- Server writes joinedAt.

POST /api/live-classes/<class_id>/leave
- Authenticate student.
- Find the student's active attendance session.
- Server writes leftAt.
- Calculate duration server-side.

The browser must never submit joinedAt, leftAt, duration, or attendance status as trusted values.

## Recording
GET /api/live-classes/<class_id>/recording
- Authenticate.
- Verify enrollment/authorization.
- Verify class is completed.
- Verify recording has been published.
- Return a short-lived signed/temporary URL where the storage provider supports it.

Do not expose permanent private storage URLs in public documents.

## AI Summary
POST /api/live-classes/<class_id>/ai-summary
- Teacher/admin or an authorized server job triggers generation.
- Retrieve the approved transcript/lesson material.
- Generate a curriculum-grounded summary.
- Save summary status: PENDING, PROCESSING, READY, FAILED.
- Save source references and generatedAt.
- Students may read only READY summaries for classes they are authorized to access.

## Practice Questions
When a summary is READY:
- Generate a small practice set from the lesson context.
- Store lesson/class linkage.
- Do not expose teacher answer keys to students.
- Grade submissions server-side.
