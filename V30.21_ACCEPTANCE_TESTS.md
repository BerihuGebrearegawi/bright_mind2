# V30.21 Acceptance Tests

- Unlinked parent cannot access a child's progress.
- Parent can see only verified linked children.
- Student cannot access parent-only analytics.
- Parent cannot modify grades, attendance, or teacher records.
- Progress is calculated from server-trusted events.
- Topic mastery is recalculated consistently.
- Risk level uses multiple signals.
- Analytics do not expose private data belonging to another student.
- Deleted/revoked parent-child links immediately block access.
