# BMT V31.62 — Certificate Verification Hardening

Additive hardening of the certificate verification boundary. Cloud B Digital Library/Scanner/Book Reader code is not modified.

- Certificate issuance now requires BMT_CERT_VERIFY_SECRET to be configured.
- Certificate verification now always validates the stored HMAC signature; an absent secret is an operational configuration error rather than a silently weaker verification mode.
- Public certificate responses no longer expose the internal verification HMAC signature.
- Existing finalized-award eligibility, idempotent certificate creation, and revoke flow remain intact.
